# 林师父｜紫微斗数 · 居家风水

完整的静态网站源文件，采用中文内容、金色／白色／米色主题，并包含透明背景个人照片。

## 文件

- `index.html`：页面内容。
- `styles.css`：样式、响应式布局及动画。
- `site.js`：移动菜单及互动效果。
- `founder-cutout.png`：已去背景的个人照片。
- `.nojekyll`：供 GitHub Pages 使用。

无需安装依赖、运行构建或配置服务器。双击 `index.html` 可以查看；Google Fonts 字体需要联网，离线时会使用系统备用字体。

## 上传到 GitHub

1. 解压 ZIP。
2. 打开你的 GitHub 仓库，选择 **Add file → Upload files**。
3. 上传解压后的文件，确保 `index.html` 位于仓库根目录。不要只上传 ZIP，也不要把整个外层文件夹作为网站根目录。
4. 填写提交说明并提交。

如果已有本地克隆的仓库，将这些文件复制到仓库根目录，检查改动后提交并推送即可。注意保留仓库已有文件，避免覆盖其他项目。

官方说明：[上传文件到仓库](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)。

## 可选：使用 GitHub Pages 发布

上传到仓库不等于发布网站。如果要使用 GitHub Pages：

1. 打开仓库 **Settings → Pages**。
2. 在 Source 中选择 **Deploy from a branch**。
3. 选择存放文件的分支（通常为 `main`）和 **/(root)**，然后保存。

仓库和账户需支持 GitHub Pages。发布后的网站通常对公众开放；本导出文件不包含原 Sites 平台的登录保护。

官方说明：[设置 GitHub Pages 发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
